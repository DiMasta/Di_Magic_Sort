# Di Magic Sort

A simple web version of the "Magic Sort" liquid sorting puzzle.

Tap a tube to pick it up, then tap another tube to pour. Liquid can only be
poured onto the same color or into an empty tube, and only if there is room.
A level is finished when every tube holds a single color. A bottle that is
full of one color gets a cork and can't be used any more.

Every 5th level (marked with a star) is a **big level**, like in the real
game: a few colors spread over many bottles, plus tall **collector** bottles
with a rope and a color tag. A collector only takes its own color, holds all
of it, and liquid can't be poured back out of it. A big level is finished
when the collectors are full and every other bottle is sorted.

Some big levels have variations from the real game:
- an **open collector**: a tall bottle with no tag, which takes whichever
  color you pour into it first and then only that color;
- **no empty bottles**: the tall bottle in the middle is the only free space.

The colors change every 5 levels between three themes: **night** (bright
colors on purple), **stone** (earthy colors on grey) and **lagoon** (bright
colors with white and red on deep teal).

- **Undo** takes back the last move.
- **Restart** starts the level again.
- **+1 Tube** adds one extra empty tube (once per level) if you get stuck.
- The speaker button turns the sounds (pick up, put down, pour, cork,
  level complete) on or off.

Progress is saved in the browser, so finished levels stay green and the next
level unlocks.

## Playing

No build step is needed. Either open `index.html` in a browser, or serve the
folder, for example:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

It also works as-is on GitHub Pages (Settings → Pages → deploy from branch).

## Levels

There are 90 levels. Normal levels start with 2 colors and add colors as you
go, up to 12 colors, and the last ones use taller tubes (5 and then 6
layers). Big levels (5, 10, ... 75) grow from 8 bottles with one collector
up to 34 bottles with two collectors.

The levels live in `js/levels.js` and are generated by:

```sh
node tools/generate-levels.js
```

The generator shuffles colors with a fixed seed (so the levels are always the
same) and runs a solver on each one, so every level is guaranteed to be
solvable. To change the difficulty curve, edit `PLAN` (normal levels) or
`BIG_PLAN` (big levels) at the top of `tools/generate-levels.js` and run it
again.

## Files

- `index.html` – level select page
- `level.html`, `js/game.js` – the game board and the color themes
- `js/rules.js` – pouring rules, shared by the game and the generator
- `js/progress.js` – saved progress
- `js/sound.js` – sound effects, made with the Web Audio API (no sound files)
- `js/levels.js` – generated level data
- `css/style.css` – styles
